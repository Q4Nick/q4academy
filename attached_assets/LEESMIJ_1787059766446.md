# De modellen van Q4 Profielen — los te gebruiken

Deze map bevat de drie klikbare modellen van de Q4-website, losgemaakt van de
site:

| Bestand | Model |
| --- | --- |
| `disc-model.html` | DISC — het Communicatie Grid met de vier temperamenten |
| `waarden-model.html` | Waarden — de vier perspectieven op twee assen |
| `eqi-wheel.html` | EQ-i 2.0 — vijf composieten en vijftien subschalen |

`index.html` is een overzichtspagina die de drie aan elkaar knoopt; handig om
de map als geheel door te geven.

## 1. Openen

Dubbelklik een bestand, of sleep het in een browser. Elk bestand bevat alles wat
het nodig heeft: de tekening, de teksten, het lettertype, het logo en de
JavaScript. Er is geen internetverbinding, server, API of build-stap nodig.

## 2. In een andere website of een ander Replit-project plaatsen

Zet de bestanden neer waar het project ze kan serveren — in een Replit-project
met een web-app is dat de map `public/` — en verwijs ernaar met een iframe:

```html
<iframe
  src="/waarden-model.html"
  title="Waardenmodel"
  style="width: 100%; height: 1100px; border: 0"
  loading="lazy"
></iframe>
```

Een iframe schaalt niet vanzelf mee met zijn inhoud, dus kies een hoogte die
past. Op een breed scherm (vanaf ongeveer 1024 px) staan het model en de uitleg
naast elkaar en volstaat ongeveer 900–1100 px. Daaronder staan ze onder elkaar
en is meer hoogte nodig, ongeveer 1600 px.

De bestanden werken ook zonder web-app: ze mogen in een map met statische
bestanden staan, of als bijlage worden gemaild.

## 3. Taal

Alle drie starten in het Nederlands, met rechtsboven een schakelaar tussen
Nederlands en Engels. Twee instellingen via de URL:

- `disc-model.html?lang=en` — start in het Engels.
- `disc-model.html?switcher=off` — verbergt de taalschakelaar, handig als de
  omringende pagina de taal al bepaalt. Combineren mag:
  `?lang=en&switcher=off`.

## 4. Bedienen

Alle drie werken met de muis én met het toetsenbord. Klik een vlak of een schaal
aan om de uitleg vast te zetten; met de muis erover zweven geeft een voorbeeld.
Met Tab loop je langs de knoppen, Enter of spatie kiest, en Escape zet de
selectie terug naar het begin.

## 5. De React-variant van het EQ-i wiel (map `react/eqi-wheel/`)

Voor een project dat al met React werkt is het EQ-i wiel er ook als broncode.
Vier bestanden plus het logo:

| Bestand | Wat het is |
| --- | --- |
| `EqiWheel.tsx` | het component zelf |
| `eqiWheel.ts` | de gegevens en de geometrie van het wiel (NL + EN) |
| `eqiColors.ts` | de vijf composietkleuren |
| `lang.tsx` | kleine taalvoorziening (`LangProvider` + `useLang`) |
| `mhs-logo.png` | het MHS-logo linksonder bij het wiel |

Gebruik:

```tsx
import { LangProvider } from "./lang";
import { EqiWheel } from "./EqiWheel";

export function Page() {
  return (
    <LangProvider initialLang="nl">
      <EqiWheel wide />
    </LangProvider>
  );
}
```

Wat het project moet meebrengen:

- React 18 of 19.
- Een bundler die TypeScript, JSX en `import logo from "./mhs-logo.png"`
  aankan (Vite, Next.js, Parcel, Create React App).
- Tailwind CSS. Het component is met Tailwind-klassen opgemaakt. Zonder
  Tailwind staat het wiel er wel, maar de omlijsting eromheen niet.
- Eén eigen regel CSS voor de kleur van de koppen, die op de Q4-site uit de
  huisstijl komt: `.text-q4-dark { color: #0f172a; }`.
- Het lettertype Plus Jakarta Sans, anders wijken de labels in het wiel iets af
  van de website.

Eigenschappen van `EqiWheel`:

| Eigenschap | Betekenis |
| --- | --- |
| `wide` | laat het blok op brede schermen buiten de tekstkolom stappen, zodat wiel en uitleg naast elkaar passen |
| `heading` / `intro` | eigen kop of inleiding; `null` laat ze weg |
| `defaultSelected` | schaal die bij openen vaststaat (en waar Escape naar terugkeert) |
| `value` + `onChange` | de selectie van buitenaf besturen |

De taal komt uit `LangProvider`. Wisselen doe je door `setLang` uit `useLang()`
aan te roepen, of door de provider met een andere `initialLang` te gebruiken.

Het DISC-model en het waardenmodel hebben deze variant niet: die worden als
losse pagina ingesloten, niet als component overgenomen.

## Inhoud

Bij EQ-i worden de subschalen alleen bij naam genoemd, en bij DISC alleen de
vier temperamenten. De definities en de uitleg van de combinaties horen bij de
debriefing en de certificeringstraining en staan daarom bewust niet in deze
bestanden; die afspraak geldt net zo goed hier als op de website.

Het EQ-i 2.0 model is eigendom van Multi-Health Systems Inc. (MHS). Het
lettertype Plus Jakarta Sans is meegeleverd onder de SIL Open Font License 1.1.

## Opnieuw maken

De bestanden hier zijn gegenereerd uit de website zelf, zodat er geen tweede
kopie van een model ontstaat die kan gaan afwijken. Na een wijziging aan een
model op de site maak je de map opnieuw met:

```
pnpm --filter @workspace/q4-profiles run export:modellen
```
